# Art assets

Shark part PNGs live here. All parts share one **1672 × 941** canvas and are
pre-registered — draw each at (0,0) and apply only the transforms in
`../docs/handoff.md`. Stacking them untransformed reproduces the shark exactly.

Draw order (back to front): `Pectoral_Fin_Rear`, `Tail_Fin`, `Blank_Body`,
`Dorsal_Fin`, `Black_part_of_mouth`, `Lower_Jaw`, `Upper_Jaw`, `Pectoral_Fin`.

PNGs are fine to commit (small). **PSD source files are git-ignored** — keep those
elsewhere. See the "Art asset generation notes" section of the handoff before generating
any new parts (magenta key, palette hexes, never generate head parts in isolation).
